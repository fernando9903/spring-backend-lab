# Spring Backend Lab

Personal learning repository focused on strengthening my Java backend skills
with Spring and Spring Boot during Q4 2026.

## Main Goal

Complete my Spring Boot course and build a solid understanding of:

- Spring Core
- Dependency Injection
- Spring Beans
- REST APIs
- Spring Data JPA
- Spring Security
- Transactions
- Caching
- AOP
- Configuration & Profiles
- Actuator & Observability
- Docker
- AWS

## Learning approach

For each topic:

1. Learn the concept.
2. Build a small example.
3. Experiment with the code.
4. Break it intentionally.
5. Understand why it fails.
6. Document the main lesson.
